## UI a UX

UI/UX beru jako součást architektury produktu, ne jen jako vizuální doplněk. Cílem je, aby uživatel rychle pochopil, co služba nabízí, jaký má další krok a jak se dostane ke kontaktu nebo poptávce.

- jasná první obrazovka s identitou, hodnotou a primární akcí,
- responzivní rozhraní pro mobil i desktop,
- přehledná navigace a sémantická struktura,
- konzistentní typografie, kontrast, spacing a vizuální identita,
- promyšlené kontaktní a konverzní cesty,
- PWA-ready chování pro instalaci webu jako aplikace,
- světlý/tmavý režim tam, kde zlepšuje použitelnost a ladí se značkou.

Portfolio **fkdev.xyz** je postavené právě tímto směrem: prémiová vizuální identita, kompaktní navigace, službově orientovaný obsah, ověřené kontaktní údaje, PWA metadata a responzivní theme-aware rozhraní.
